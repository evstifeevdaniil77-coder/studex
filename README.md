# Навигатор поступления

Бесплатный сервис для учеников:

- **Таджикистан (ММТ)**: подбор специальностей по кластеру и баллу ММТ на основе официальных отчётов ntc.tj.
- **Зарубежные вузы (IELTS / TOEFL)**: анкета из 5 полей. Заявка сохраняется в базу, администратор получает уведомление в Telegram.

В проекте нет тестовых или выдуманных данных. База специальностей изначально пустая и заполняется только импортом реальных отчётов.

## Требования

- Node.js 22.13 или новее (используются встроенные `node:sqlite` и `fetch`, сторонние npm-пакеты не нужны).
- Python 3.10 или новее — только для импорта отчётов.

## Запуск

```bash
cp .env.example .env      # заполните BOT_TOKEN, ADMIN_CHAT_ID, USD_TJS_RATE
npm start                 # http://localhost:3000
```

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота (от @BotFather) |
| `ADMIN_CHAT_ID` | ID чата администратора, куда приходят заявки |
| `USD_TJS_RATE` | Курс: сомони за 1 USD. Если не задан, цены в USD не показываются |
| `RISK_MARGIN` | На сколько баллов ниже проходного вариант ещё помечается как [РИСК] (по умолчанию 15) |
| `AD_COURSES_TEXT`, `AD_PRIVATE_TEXT` | Тексты двух рекламных блоков (курсы подготовки к ММТ, частные вузы) |
| `DB_PATH`, `PORT` | Путь к базе SQLite и порт |

## Загрузка официального датасета НТЦ (Excel)

```bash
pip install -r scripts/requirements.txt
python scripts/import_excel.py                       # читает data/dataset_mmt_2026.xlsx
python scripts/import_excel.py другой_файл.xlsx --db data/navigator.db
```

- Лист `Специальности_2026` загружается в `specialties`, старые записи удаляются полностью.
- Лист `Контакты_вузов` загружается в `institutions`. Скрипт чинит артефакты PDF (оторванные «ш»/«н» от «шаҳри»/«ноҳияи», куски названия региона в названии и адресе) и сопоставляет учреждение с вузом из листа специальностей. Так в карточке видны адрес и телефон приёмной комиссии.
- Из листа `Сводка` берутся названия кластеров (таблица `clusters`).
- В конце скрипт выводит проверку: число записей по каждому кластеру (ВУЗ / колледж, бюджет / контракт, места, сколько программ уже с баллом).
- Таблица заявок `abroad_leads` не затрагивается.

Пока `min_score_prev` пуст, сайт показывает метку `[ПРОХОДНЫЕ БАЛЛЫ ОЖИДАЮТСЯ]` и сортирует так: сначала бюджет, затем контракт от дешёвого к дорогому, затем по числу мест. Балл ученика при этом вводить не обязательно. Как только в базе появляются баллы, «Светофор» включается сам:

- бюджет и балл ≥ проходного: `[ВЫСОКИЙ ШАНС]`
- контракт и балл ≥ проходного: `[РАБОЧИЙ ВАРИАНТ]`
- балл ниже проходного не больше чем на `RISK_MARGIN`: `[РИСК]`

## Добавление проходных баллов (ntc.tj / stat.ntc.tj)

```bash
# 1. Проверка без записи: как распознались колонки
python scripts/import_ntc.py reports/klaster_1.pdf --cluster 1 --dry-run --csv-out check.csv

# 2. Дописать баллы в min_score_prev
python scripts/import_ntc.py reports/*.pdf

# Перезаписать уже заполненные баллы
python scripts/import_ntc.py reports/*.pdf --overwrite
```

Скрипт не создаёт новые программы. Он находит уже загруженные по коду специальности, вузу и типу оплаты (бюджет / договор) и заполняет `min_score_prev`. Записи отчёта, которых нет в базе, выводятся списком.

Что ещё умеет скрипт:

- Читает PDF (`pdfplumber`), CSV (кодировки UTF-8/UTF-16/CP1251, разделитель определяется сам) и XLSX (`pandas`).
- Распознаёт заголовки колонок на русском и таджикском («Рамзи ихтисос», «Муассисаи таҳсилоти олӣ», «Холи гузариш», «Шакли таҳсил» и т.д.).
- Исправляет таджикские буквы: старые шрифты (ќ ѓ њ ї ў љ → қ ғ ҳ ӣ ӯ ҷ), похожие буквы других алфавитов, латиницу внутри кириллических слов, Unicode NFC.
- Объединяет строки «ройгон / пулакӣ» (бюджет / договор) одной специальности в одну запись.
- Определяет кластер по колонке, по строке-разделителю «Кластери 2», по имени файла (`klaster_2.pdf`) или по флагу `--cluster`.
- Если колонка не распознана, её можно указать вручную: `--map score_budget="Заголовок колонки"`.
- Строки без кода, вуза, кластера или балла не придумываются, а пропускаются, и скрипт выводит их число с причиной.

## Структура

```
server.js                HTTP-сервер и API
db/schema.sql            таблицы specialties, institutions, clusters, abroad_leads
public/                  интерфейс (HTML, CSS, JS без библиотек и иконок)
scripts/import_excel.py  загрузка официального датасета НТЦ (Excel)
scripts/import_ntc.py    добавление проходных баллов из отчётов ntc.tj
data/dataset_mmt_2026.xlsx  официальный датасет
data/navigator.db        база (создаётся при импорте / первом запуске)
```

API:

- `GET /api/stats`: число специальностей, кластеры, уровни, формы обучения, города, языки, курс
- `GET /api/specialties?cluster=1..5[&score=N&level=&study_form=&city=&language=]`: подбор с метками `pending` / `high` / `working` / `risk` и контактами приёмной комиссии
- `POST /api/abroad-leads`: сохранение заявки и уведомление в Telegram
